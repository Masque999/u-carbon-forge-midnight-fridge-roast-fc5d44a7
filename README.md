# Midnight Fridge Roast

One line, 1-200 characters: roast the fridge at midnight.

Entry: `At midnight my fridge hums a little louder, as if it knows I am standing there in the dark, negotiating with the leftovers.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
